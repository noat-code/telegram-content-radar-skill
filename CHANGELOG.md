# Changelog

## 0.2.5 - 2026-10-14

- Made the editorial interview a hard gate before the first meaningful scan.
- Expanded the private editorial profile with core-reader, author-position, reader-job, evidence, and decision-rule maps.
- Added an audience-fit rule: an idea cannot be draft-ready when the audience, reader job, or author proof is unknown.

## 0.2.4 - 2026-10-14

- Made report delivery in chat mandatory before ideation or drafting.
- Added full scan triage without an arbitrary limit on qualified angles.
- Added `Now`, `Later`, `Maybe / needs evidence`, `Question for author`, and `Discard` statuses.
- Added backlog rules for kept ideas and a question status for genuinely ambiguous fits.
- Updated the weekly report template with visual navigation and triage fields.

## 0.2.0

- Added safe Telegram API onboarding, editorial intake, finding and idea cards, scoring, and weekly review workflow.
