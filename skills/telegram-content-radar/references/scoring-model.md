# Scoring Model

Score every candidate from 0 to 3 on each dimension. The score estimates whether a source signal can become an original post for this user, not whether the source post was popular.

## Audience-fit gate (before scoring)

A shared broad topic is not enough. Before scoring, confirm that the source and author's core reader overlap in reader context, problem, desired outcome, and acceptable author position. If the post serves a different reader job, level, or promise, reject it as off-position. If the fit is plausible but unknown, mark it `Question for author` or `Maybe / needs evidence` rather than pretending the score is certain.

Audience fit is a gate, not a sixth point category. The total score remains 0–15.

## Relevance to the user's channel

- `0` - outside the editorial profile.
- `1` - connection is vague or forced.
- `2` - belongs to a content lane.
- `3` - directly strengthens the channel's position.

## Reader usefulness

- `0` - news, noise, or an unsupported opinion.
- `1` - interesting but has no practical implication.
- `2` - helps the reader understand a mechanism, mistake, or scenario.
- `3` - helps the reader make a decision, test a method, or avoid a costly error.

## Genuine own angle

- `0` - would require copying or borrowed authority.
- `1` - only a generic rephrasing is possible.
- `2` - the user has a different framing, example, or limitation.
- `3` - the user has direct experience, data, a test, or a distinct position.

## Original-post potential

- `0` - produces a rewrite.
- `1` - the topic is overused and needs substantial work.
- `2` - can become an independent post.
- `3` - naturally becomes a distinctive post or series.

## Hook or format strength

- `0` - delivery adds nothing.
- `1` - one useful element exists.
- `2` - clear structure or meaningful conflict.
- `3` - the format helps explain something difficult, creates recognition, or earns attention without hype.

## Decision

- `0–7` - reject.
- `8–11` - add to idea bank.
- `12–15` - create an idea card and prepare an outline.

Any failed originality gate overrides the numeric result.
